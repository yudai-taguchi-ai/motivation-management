# motivation-management

自分の調子を記録して、振り返るためのアプリ。

- 1日の調子を、グラフ上に自分で曲線を描いて記録する
- 時間帯ごとに「何をしたか」をメモし、タグを付ける
- 日単位・月単位で見返し、どの行動で調子が上がったかを確かめる

デザインは白黒のみ。濃さ（黒・グレー・薄いグレー）で区別する。

## 動かし方

```
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開く。

## 決まったこと（2026-10-07）

| 項目 | 決定 | 理由 |
|---|---|---|
| 使う端末 | スマホと PC を半々 | 記録はスマホ、振り返りは PC が多い想定 |
| 形 | Web アプリ（PWA） | 1つ作ればスマホでも PC でも開ける。スマホはホーム画面に追加して使う |
| データの保存先 | クラウド（Supabase） | 半々で使うので、スマホで描いたものを PC で見られる必要がある |
| ログイン | 必要（自分だけが見られる） | 公開 URL で動かすため |
| 縦軸 | 0〜100 の数値。画面に数字を出す | |
| 横軸 | 6:00〜翌2:00（設定で変更できるようにする） | 睡眠中を空白にしない |
| メモ | 時間帯＋本文＋タグ | タグがあれば行動ごとの効果を集計できる |
| 場所 | 家・大学・オフィス・ジム・その他（自由記述）を時間帯で記録し、グラフの背景に出す | 場所ごとの調子を比べられる。白黒なので灰色の濃さと模様で区別し、凡例を付ける |
| カフェイン | とった時刻（5分刻み）と、任意で何をとったかを記録し、グラフに縦線を引く | カフェインの後に調子がどう動くかを見る |
| 技術 | Next.js + TypeScript、Vercel に公開 | Affectify の Portal AI と同じ組み合わせ |

### 日の表示

- その日の曲線と、メモがある時間帯を重ねて表示する
- 曲線を描く・直す、メモを追加・編集・削除する

### 月の表示

- 日ごとの平均値の折れ線（1か月分）
- 日 × 時間帯の表（濃いほど調子が高い）。「毎日何時ごろに落ちるか」を見る

### タグの集計

- タグごとに「その時間帯の始まりの値 → 終わってから1時間後の値」の変化を平均する
- 例：`#散歩 12回 平均 +11` `#SNS 8回 平均 -6`

## データの持ち方

描いた線は絵として保存しない。絵のままでは平均や変化量を計算できないため、
**15分ごとの数値**に直して保存し、表示するときになめらかにつなぐ。

```
描いた線      ～～～／＼＿＿／～～
                ↓ 15分ごとに高さを読み取る
保存する値    6:00=55, 6:15=58, 6:30=60, ... 25:45=40（1日 80 個）
```

### テーブル（Supabase）

`days` … 1日1行。その日の記録をまとめて持つ（定義は `supabase/migrations/`）

| 列 | 型 | 中身 |
|---|---|---|
| user_id | uuid | 誰の記録か（ログイン中の人が自動で入る） |
| date | date | 日付 |
| mood | jsonb | 15分ごとの調子（80個。描いていない区間は null） |
| places | jsonb | 15分ごとの場所（80個。記録なしは null） |
| notes | jsonb | メモの一覧（始まり・終わりは 0時からの分。深夜1時 = 1500） |
| caffeine | jsonb | カフェインの一覧（時刻は 0時からの分） |
| updated_at | timestamptz | 最終更新 |

- 行ごとの権限（RLS）で、ログインした本人の行しか読み書きできない
- 1日の記録が空になったら行ごと消す
- 最初は「メモ用」などテーブルを分ける予定だったが、1日分をまとめて読み書きする使い方しかしないので1つにした。1年で365行なので、開いたときに全期間を読み込む

### 以前の保存（ブラウザ内）

③より前は `mood:日付` などの名前でブラウザ内に保存していた。ログインしたあと、画面上部の「クラウドに移す」で取り込める（クラウド側に同じ日の記録があれば、空いている部分だけを埋める）。

## 環境変数

`.env.local`（Git に入れない）に書く。

```
NEXT_PUBLIC_SUPABASE_URL=https://xnpcgixozcmadbjznrgn.supabase.co
NEXT_PUBLIC_SUPABASE_KEY=（Supabase の publishable キー）
SUPABASE_DB_PASSWORD=（supabase db push に使う）
```

公開は Vercel の個人アカウントで行う。Affectify のアカウントとは紐づけない。

## 作る順番

1. 日の表示で曲線を描いて保存できる（まずはブラウザ内に保存） … 済
2. メモとタグを追加・編集できる … 済
   - 場所（グラフの背景）とカフェイン（縦線）も記録できる … 済
3. Supabase に保存先を移し、ログインを付ける … 済（公開: https://motivation-management.vercel.app ）
4. 月の表示
5. タグの集計
6. PWA にしてスマホのホーム画面に置けるようにする
